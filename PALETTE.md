# Midnight navy palette

| Role | Color | Use |
| --- | --- | --- |
| Background | `#0B1020` | Deep navy behind figures |
| Surface | `#151D32` | Cards and secondary panels |
| Main text | `#E7ECF5` | High-contrast labels |
| Muted text | `#A9B4C8` | Captions and supporting text |
| Teal | `#4FD1C5` | Primary accent |
| Violet | `#A78BFA` | Secondary accent |
| Amber | `#F4B860` | Highlight when a third series is needed |

The report's scientific graphics were supplied as raster PNGs embedded in a Word document. Their dark displays are generated by [`scripts/build_dark_figures.py`](scripts/build_dark_figures.py), which embeds each source image in an SVG and applies the same color transfer to every pixel. This keeps geometry, text, data marks, and numbers in their original positions. The dark SVGs are presentation assets; use the original PNGs for source inspection.

GitHub controls the surrounding README page theme, so the palette applies to the figures and repository graphics rather than forcing a theme on the GitHub interface.
